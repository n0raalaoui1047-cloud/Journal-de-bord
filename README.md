- 1: sélectionner *nouvelle image*
- 2: vérifier les réglages -> l'affiche doit être de 1920 x 1080 pixels
- 4: faire un clic droit pour sélectionner un outil et la couleur rapidement (peut aussi servir à zoomer)

- 5: pour créer un calque vectoriel ou autre, cliquer sur la flèche à côté du + dans les calques
